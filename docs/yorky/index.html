Skill guide

☕ yorky

Translate prose into Yorkshire dialect at three strengths while preserving code identifiers, URLs and logic.

Read the skill protocol →

What it does

yorky is the short callable name for yorkshire-pudding. Choose mild, proper or broad dialect.

The prose tool and the agent’s code-editing protocol are distinct: identifiers, keys, URLs, placeholders and program behaviour must remain intact.

What you need

A compatible agent harness; Node.js for the bundled deterministic prose translator. Code translation follows the skill’s protected-zone rules.

Install and use

Clone the public skills collection, then preview installation into your chosen compatible harness. This example selects Codex; use the installer’s documented target for another harness.

git clone https://github.com/marroccofella/skills
cd skills
node install.mjs --target codex --dry-run

After checking the preview, repeat without --dry-run. Invoke yorky in your agent and follow the linked skill protocol.
