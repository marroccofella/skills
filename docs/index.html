◆ skills

Portable, cross-harness Agent Skills. Source and docs: github.com/marroccofella/skills

Five skills, callable by name

momm — local multi-CLI code review with a reproduction gate · myvoice — consented local voice cloning · myrepo — publish to GitHub with a live page · myautoness — self-playing by search and verified replay · yorky — Yorkshire dialect. Plus myskills, which runs them all and reports one verdict.

Install every skill into the harness you name (the installer will not guess):

git clone https://github.com/marroccofella/skills && cd skills && node install.mjs --target claude
