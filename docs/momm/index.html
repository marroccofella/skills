◆ MOMM · MIXTURE OF MODEL MODALITY

Every frontier model on your machine, reviewing your code together.

MOMM is an Agent Skill for AI coding agents. Your agent dispatches a diff to the other installed LLM CLIs — OpenAI Codex, Claude Code, Google Antigravity, GitHub Copilot, xAI Grok — which review it in parallel and return structured, deduplicated findings. Your agent stays the sole writer, must reproduce every claim before acting, and seals the whole conversation as content-addressed evidence.

The coalition

Five minds. One gate. No blind trust.

Reviewers are read-only diagnostic instruments — their output is evidence, never instructions. The governor (your agent) self-excludes from reviewing its own work, and no finding is acted on by vote: it must be reproduced first.

Evidence, not vibes

Every claim resolves to a hash.

Reports are content-addressed (sha256 over stored bytes) and bound to the exact reviewed input by its own hash. Every reviewer suggestion gets an explicit applied-or-rejected disposition with named evidence. Release gates can demand a quorum — timeouts cannot silently thin the coalition. And MOMM eats its own cooking: every version of MOMM was reviewed by MOMM, and the sealed ledger is public.

Get started

Three commands to a five-model review.

  1. Clone and link into every detected harness (Claude Code, Codex, Gemini, Antigravity — junctions on Windows, symlinks elsewhere):

    git clone https://github.com/marroccofella/skills && node skills/momm/scripts/install.mjs --target all

  2. Check every route — zero model calls; prints the exact install/login command for anything that’s down:

    node skills/momm/scripts/multi-review.mjs --preflight --pretty

  3. Review your changes (or just tell your agent “use momm”). Your private dashboard is one more command: node skills/momm/scripts/ledger.mjs --open

    git diff HEAD | node skills/momm/scripts/multi-review.mjs --governor claude --pretty
