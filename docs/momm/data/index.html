◆ MOMM page data

The tables behind the momm page, as CSV, regenerated with the public evidence export and its digest. Self-review numbers: every run is this project reviewing itself.

  • routes.csv — per route: completed reviews, timeouts, median and p90 seconds, verdict counts, mean confidence, suggestions applied and rejected, governor acceptance rate (applied ÷ adjudicated — not precision).
  • runs.csv — every run: id, time, driving harness, input bytes, findings, corroborated count, per-route status, subject.
  • findings-by-severity.csv — raw findings by reviewer-assigned severity, before reproduction.
  • input-size-vs-time.csv — per report: input KB, routes dispatched, routes timed out, slowest completed reviewer in seconds.
  • runs-per-day.csv
  • dispositions.csv — every applied / rejected / deferred ruling with its reason and run id.

Source of truth: momm-evidence.json and its sha256 sidecar.
