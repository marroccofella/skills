What MOMM is for

The short name is spoken like “mom.” It means Mixture of Model Modality: a selected review team around the coding agent you already use. The governor is the accountable lead editor and referee. Reviewers are inspectors. Their output is evidence to reproduce, not a vote to obey.

Version 1.16.0 adds explicit cost and token accounting, reliability ratings, capability-aware routes, split and per-piece quorum, parallel jobs, retry-invalid handling, and a shared Setup Center and ledger design. Quorum is the minimum number of independent inspectors needed before a gate opens, like two signatures on a safety checklist. Provider accounts, quotas, and supported modalities still determine what a real run can do.

Transcript

In simple terms, the mom skill gives your coding agent a review team. It lets other tools inspect a change before you ship it. One governor stays responsible for the final decision. Your agent is still the only writer and verifier.

The name expands to Mixture of Model Modality. Say the short name like mom. It is not a new model. It is not a vote. Think of the reviewers as inspectors with different specialties. The governor is the lead editor, project manager and referee.

AI can be fast and still miss an edge case, a security boundary or a confusing explanation. The five-part loop takes a baseline, dispatches selected reviewers, investigates each claim, fixes only what evidence supports, and records the result in a private audit notebook.

A reviewer’s claim is a proposition. It is not a fact yet. The governor reproduces it, or rejects it with evidence. Quorum is the minimum number of independent signatures needed before a gate opens. Think of two signatures on a safety checklist.

The 1.16.0 workflow records cost, tokens, reliability, ratings, capabilities, quorum and retries. Reviews can run in parallel, but more inspectors still consume more quota.

Install the stable release, connect one reviewer with its official account login, choose what may leave your machine, and ask the mom skill to review a meaningful change. Then open the ledger and judge what was useful on your own work.
