What MOMM is for

The short name is spoken like “mom.” It means Mixture of Model Modality: a selected review team around the coding agent you already use. The governor is the accountable lead editor and referee. Reviewers are inspectors. Their output is evidence to reproduce, not a vote to obey.

Version 1.16.0 adds explicit cost and token accounting, reliability ratings, capability-aware routes, split and per-piece quorum, parallel jobs, retry-invalid handling, and a shared Setup Center and ledger design. Quorum is the minimum number of independent inspectors needed before a gate opens, like two signatures on a safety checklist. Provider accounts, quotas, and supported modalities still determine what a real run can do.

Transcript

Your AI agent can write a patch in seconds. That is useful. It is also exactly when a missed edge case can become tomorrow's outage. MOMM is the review team you add before the send button.

MOMM gives one responsible agent a set of independent inspectors. The inspectors challenge the work. One governor checks their claims, reproduces what matters, and stays responsible for the decision. Your project still has one writer.

Imagine a lead editor preparing a story. Inspectors mark different problems in the margins. A referee checks the evidence before the story goes live. That is MOMM: not a popularity poll, not a new model, and not permission for another tool to edit your project.

MOMM means Mixture of Model Modality. Say the short name like mom. Modality means the kind of evidence a route can handle: code and text, images, PDFs, audio or video where its capability registry says it can. Unsupported media is disclosed, not guessed.

First, capture a baseline. Next, send only the scoped work to selected routes in parallel. Then turn reviewer output into claims. Reproduce each material claim with a test, a source check or a rendered result. Finally, record the ruling, the evidence and the uncertainty in the private ledger.

Quorum is a minimum success count, like two signatures on a safety checklist. Version 1.16.0 adds accounting, ratings, trusted guidance, split work, parallel jobs, capability-aware media routing, explicit update checks and opt-in retry-invalid handling.

MOMM is not a universal accuracy guarantee. Providers can be unavailable. Quota is real. Unknown usage stays unknown. Capability coverage is reported, not implied. Human acceptance and release permission remain yours. Start with one meaningful change, inspect the evidence, and keep the review team accountable.
