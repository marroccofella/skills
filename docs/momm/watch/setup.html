What will MOMM change?

Bring your chosen AI review tools into one workflow. Your current agent remains the only writer; external reviewers challenge the work, and the governor investigates and records each decision. Parallel review reduces manual coordination, but adds provider usage. No universal time-saving or accuracy percentage has been established.

Full transcript

0:00 · Your first reviewer. Ready to go.

This is the practical setup. The website explains MOMM. The Setup Center connects your tools. The ledger records your reviews. Three different jobs. Let's get your first reviewer ready.

0:11 · 01 / Install for your own agent

Open the installation guide. Copy the install or upgrade prompt into the agent you use. It checks Git, Node eighteen or newer, your existing installation, and the published stable release. Choose a permanent folder outside your projects. Review the plan, then approve it. You don't need every harness, or every reviewer.

0:32 · 02 / Open the local Setup Center

Ask your agent to open MOMM's Setup Center. If you prefer the terminal, run the setup command from the skills clone. The address is local to your machine, and its port may differ from this recording. Don't paste somebody else's localhost address and expect their dashboard.

0:48 · 03 / Choose who is driving

Choose your current agent as the governor. That's the agent writing and testing your work. It is excluded from reviewing itself. Now pick an external reviewer. One is enough to begin. Add more when another perspective is worth the extra quota.

1:04 · 04 / Connect, then verify

An installed command line tool is not the same as a working account. Use its official login action and complete the browser login yourself. No API keys. Then verify the connection. Quick Setup tests detected sessions using a disclosed synthetic sentence, not your project. A successful check is evidence for now, not a promise about every future review.

1:24 · 05 / Check versions without auto-updates

The maintenance panel separates installed versions from update availability. Check first. Read the proposed change. Run an update only when you choose to. MOMM's own signed updates also protect protocol changes with explicit acceptance. If you update MOMM, relaunch Setup Center so you're not looking at an older running page.

1:45 · When a route is not ready

Follow the actual status. Missing means install the official tool. Authentication required means complete its login. Provider unavailable means wait and retry, not re-login. Quota exhausted means deal with the provider's allowance. You can continue with another ready reviewer; don't turn a failed route into a successful one on the screen.

2:06 · 06 / Return to your project

Back in your project, approve which providers may receive the work. Ask MOMM to review your changes, investigate material findings, verify fixes, record every decision, and give you the ledger link. That completes the journey: set up once, request a review, then check what happened.
