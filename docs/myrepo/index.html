Skill guide

↗ myrepo

Publish a project to GitHub with a Pages site, a preview, privacy and secret checks, and live-URL verification.

Read the skill protocol →

What it does

Publishes browser-ready projects, or provides a landing page for projects that need local software. Preserves existing documentation by default.

Checks publishable files and the Git history being introduced for secrets and machine-specific paths. Its offline self-test checks safety gates separately from GitHub account readiness.

What you need

Node.js and GitHub CLI with your existing OAuth login. Public publishing follows your approval and a dry-run preview.

Install and use

Clone the public skills collection, then preview installation into your chosen compatible harness. This example selects Codex; use the installer’s documented target for another harness.

git clone https://github.com/marroccofella/skills
cd skills
node install.mjs --target codex --dry-run

After checking the preview, repeat without --dry-run. Invoke myrepo in your agent and follow the linked skill protocol.
