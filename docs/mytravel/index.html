Skill guide

✈ My Travel

Compare complete journeys and reservations using your available tools, then verify bookings within your authorisation.

Read the skill protocol →

What it does

Considers dates, airports, cabins, loyalty options, stopovers and ground transport against the user’s requirements. Challenges the preferred itinerary and checks the completed booking and usable benefits.

Synthetic decision checks cover planning rules; they do not establish that a live fare is available or that a booking has succeeded.

What you need

A compatible agent harness and suitable travel/search tools or authorised browser sessions. The skill does not bundle a booking engine or account access.

Install and use

Clone the public skills collection, then preview installation into your chosen compatible harness. This example selects Codex; use the installer’s documented target for another harness.

git clone https://github.com/marroccofella/skills
cd skills
node install.mjs --target codex --dry-run

After checking the preview, repeat without --dry-run. Invoke $mytravel in your agent and follow the linked skill protocol.
