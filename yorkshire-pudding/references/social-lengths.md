# Social-copy length guide

Checked 2026-09-18. These are working ranges for testing, not universal
“perfect” lengths. Audience, format, topic, media, and the first line usually
matter more than hitting a character target. The maximum is a ceiling, not a
goal.

| Network | Normal text ceiling | Practical starting point for engagement |
|---|---:|---:|
| X | 280 characters | 71–100 characters for an everyday post |
| X Premium | 25,000 characters | Still start short; use longer posts for threads or deep-dives |
| Instagram caption | 2,200 characters | 138–150 characters for organic captions; under 125 for sponsored copy |
| Facebook organic post | 63,206 characters | 1–80 characters for a single-idea feed post |
| LinkedIn post | 3,000 characters | Put the hook and anchor inside the first ~150–200 characters; no universal whole-post optimum |
| Threads post | 500 characters | Under 200 characters for a conversational opener |
| Pinterest description | 500 characters | About 300 characters when search context needs room |

## Operating rule

Write the clearest version first. Then shorten until the anchor, context, and
next action still survive. Never delete a qualification, disclosure, or
essential fact merely to reach a benchmark. If the message needs more room,
split it into a thread or adapt it to the platform instead of cramming.

The X ceiling and Premium allowance come from [X Help](https://help.x.com/en/using-x/types-of-posts).
The LinkedIn ceiling comes from [LinkedIn Help](https://www.linkedin.com/help/linkedin/answer/a527227).
The engagement ranges are current cross-platform benchmarks from
[Hootsuite's 2026 guide](https://blog.hootsuite.com/ideal-social-media-post-length/)
and should be validated against the user's own analytics. A large 2026
LinkedIn study found no universal text-only sweet spot, so the guide preserves
that uncertainty rather than repeating the unsupported “1,300 characters” rule
([Flypost study](https://www.flypost.io/learn/linkedin-post-length)).
