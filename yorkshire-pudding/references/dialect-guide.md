# Yorkshire dialect guide

The working reference for every translation. The script applies the
mechanical subset; everything here is available to you when translating by
hand. Written with affection — this is a real dialect with real grammar,
not a funny voice.

## Grammar rules

### Definite article reduction (DAR)

"The" reduces to **t'** attached to the following word, pronounced as a
glottal stop rather than a spoken "t":

- down the pub → down t'pub
- put the kettle on → put t'kettle on
- the end of the day → t'end o' t'day

Never reduce "thee", "them", "these", "they". At `mild` level, leave "the"
alone entirely.

### Were-levelling

"Was" levels to **were** in all persons at `proper` and above:

- I was chuffed → I were chuffed
- it wasn't me → it weren't me

### Second person: thee / tha (broad only)

The old second-person singular survives in broad Yorkshire:

| Standard | Broad Yorkshire |
|---|---|
| you (subject) | tha ("tha knows") |
| you are | tha'rt |
| your | thi |
| yours | thine |
| yourself | thisen |

Reflexives use **-sen**: misen, thisen, hissen, 'ersen, ussens.

### Sound changes

- **G-dropping**: doing → doin', morning → mornin'. Words that merely end
  in "-ing" as part of the root keep it: thing, king, bring, string.
- **H-dropping** (broad): have → 'ave, house → 'ouse, happen → 'appen.
  Written with a leading apostrophe.
- **of → o'**, **with → wi'**: cup o' tea, wi' me mates.
- **my → me**: me 'ouse, me old mate.

### Other structures

- **us** for "our" or "me": "us dinner", "give us it 'ere".
- **while** meaning "until": "wait while five o'clock" (a famous source of
  bugs on signage — "do not cross while lights are flashing").
- **'appen** as "perhaps": "'appen it'll rain."
- **nobbut** = "nothing but / only": "he's nobbut a bairn."
- **baht** = "without" (archaic but iconic — *On Ilkla Moor Baht 'at*).
- **allus** = "always".
- Negation: in't (isn't), dun't (doesn't), wun't (won't), shun't
  (shouldn't), mun't (mustn't).

## Lexicon

### Greetings and courtesies

| Standard | Yorkshire |
|---|---|
| hello | ey up |
| goodbye | sithee / ta'ra |
| thanks | ta |
| thank you very much | ta very much |
| yes | aye |
| excuse me | 'ey up, love |

### People

| Standard | Yorkshire |
|---|---|
| child / children | bairn / bairns |
| friend | mate, owd lad, owd lass |
| fool | wazzock, pillock, barmpot |
| term of address | love, lad, lass, cock (all affectionate) |

### Adjectives and states

| Standard | Yorkshire |
|---|---|
| pleased | chuffed (very: chuffed to bits) |
| excellent | champion, grand, beltin', bobby-dazzler (noun) |
| very | proper, right, reyt ("right good") |
| sulky / moody | mardy ("he's got a monk on") |
| feels the cold | nesh |
| freezing (of a person) | nithered |
| silly | daft, gormless (clueless) |
| confused | flummoxed |
| drunk | kaylied |
| upset stomach | gipping |

### Things and places

| Standard | Yorkshire |
|---|---|
| alley between houses | ginnel, snicket |
| cup of tea | brew ("put t'kettle on, I'm gasping for a brew") |
| packed lunch | snap |
| ears | lug 'oles |
| mouth | cake 'ole |
| something / anything / nothing | summat / owt / nowt |

### Verbs

| Standard | Yorkshire |
|---|---|
| play | laik ("t'bairns are laikin' out") |
| hit | bray |
| stop it | gi'o'er |
| complain | mither (borderline Lancashire; use sparingly) |
| shut the door | put wood in t'hole |

### Exclamations

- **ee by gum** — general amazement
- **by 'eck** / **flippin' 'eck** / **'eckers like** — mild alarm
- **well I'll go to t'foot of our stairs** — full astonishment
- **give over!** / **gi'o'er!** — "you can't be serious"
- **nay, lad/lass** — gentle disagreement

## Rhythm and register

Yorkshire humour is **dry, economical, and understated**. The dialect
carries the joke; the sentence stays short.

- Prefer understatement: "not bad" is high praise; "it'll do" is approval.
- End on the dialect word where you can — punchlines land on "nowt",
  "chuffed", "wazzock", not before them.
- Don't gild it. One "ee by gum" per paragraph at most; broad text is
  broad because of grammar (tha, t', were), not because every word is
  swapped.
- Questions get tags: "grand day, in't it?", "tha knows, dun't tha?"

## Authenticity borders

Words that sound "northern" but are **not** Yorkshire — do not use them:

| Word | Actually |
|---|---|
| canny, pet, howay | Geordie (Tyneside) |
| la, boss, made up | Scouse (Liverpool) |
| gradely | Lancashire (fighting words to use it in Yorkshire) |
| duck | Derbyshire / East Midlands |
| our kid | Manchester |

Within Yorkshire, West Riding (Leeds, Sheffield, Bradford) is the default
register of this skill. North and East Riding lean closer to Durham forms
("bairn" is strongest there). Nobody will mind the blend at `proper`
level; at `broad`, stay consistent within one text.
